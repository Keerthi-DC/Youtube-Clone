# YouTube Clone - Full Stack MERN Capstone Project

A feature-rich YouTube clone built using the MERN stack (MongoDB, Express, React, Node.js). Includes video streaming player, channel management, comment CRUD, like/dislike interactions, search & category filtering, JWT authentication, and dark theme UI.

## Features
- **Authentication**: JWT-based Sign Up & Login with strict password validation.
- **Home Page**: Dynamic video grid, title search bar, category filter chips, toggleable sidebar.
- **Video Player**: Custom video playback, like/dislike toggling, complete comment CRUD (Add, Edit, Delete).
- **Channel Page**: Channel creation, video management (Upload, Edit, Delete).
- **Database**: MongoDB Mongoose schemas with dynamic fallback to `mongodb-memory-server`.
